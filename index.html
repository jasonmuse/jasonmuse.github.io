SOFTWARE

DATA DESKTOP APP

FLORIDA HURRICANE LANDFALL EVENT TRACKER

C# / ASP.NET CoreTypeScript / Electron NetTopologySuitexUnit

Parses NOAA HURDAT2 storm tracks and presents inferred Florida hurricane landfalls in a Windows desktop report.

Engineering highlight: Detects track crossings against Florida's boundary, filters inland entries from neighboring states, and preserves separate landfalls from the same storm. The included dataset produces 104 inferred events across 2,004 storms.
